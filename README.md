# Дашборд статистики звонков (Call Stats Tracker)

⚠️ **Важно:** Текущая актуальная версия проекта находится в папке `v2`.

## 📌 О проекте
**Call Stats Tracker** — это интерактивное веб-приложение, созданное для операторов колл-центров и специалистов службы поддержки. Оно позволяет удобно вести учет обработанных звонков, контролировать рабочее время (смены и перерывы), а также автоматически рассчитывать заработок на основе настраиваемых тарифов и коэффициентов.

## 🎯 Для чего нужен этот проект?
Работа в поддержке требует внимательности к таймингам и показателям (KPI). Этот инструмент помогает:
- Избавиться от ручного подсчета статистики и заработка.
- Отслеживать время звонков и поствызывной обработки (ПВО).
- Контролировать время нахождения на смене и на перерывах с помощью встроенных таймеров и уведомлений.
- Анализировать свою эффективность (процент эскалаций, среднее время звонка и т.д.).
- Легко выгружать отчетность для руководителей или для личного контроля.

## ⚙️ Как это работает и основные возможности
Приложение работает прямо в браузере и сохраняет все данные локально (в `localStorage`), что обеспечивает быстрый доступ и отсутствие необходимости в сложной настройке серверов или баз данных.

**Ключевой функционал:**
* **Учет звонков:** Добавление информации о звонке (длительность, ПВО, наличие эскалации, получение оценки).
* **Финансовый калькулятор:** Автоматический расчет заработка в бонусных/денежных единицах (БО) с учетом базовой ставки и временных множителей (например, x2 или x3 в определенные часы).
* **Управление рабочим временем:** Настройка начала и конца смены, учет перерывов/обедов с таймером обратного отсчета и всплывающими уведомлениями.
* **Адаптивный интерфейс (3 режима):** * *Легкий* — простой счетчик-кликер для быстрых отметок.
  * *Средний* — ускоренный ввод с помощью кнопок-переключателей.
  * *Сложный* — детальная настройка каждого звонка с вводом текста эскалаций.
* **Кастомизация рабочего пространства:** Все карточки-виджеты можно менять местами (Drag-and-Drop) и скрывать ненужные.
* **Темная тема:** Полноценный ночной режим для комфортной работы при слабом освещении.
* **Экспорт данных:** Выгрузка истории звонков и текстов эскалаций в формате `.xlsx` (Excel).

## 🛠 Использованные технологии
Проект представляет собой классическое Frontend-приложение (SPA-подобное), написанное без использования тяжелых фреймворков:
* **HTML5 / CSS3 / JavaScript (ES6+)** — основа логики и разметки.
* **Bootstrap 5** — UI-фреймворк для адаптивной сетки, стилизации компонентов и модальных окон.
* **Bootstrap Icons** — векторные иконки интерфейса.
* **SortableJS** — библиотека для реализации плавного перетаскивания (Drag-and-Drop) виджетов.
* **ExcelJS & FileSaver.js** — для генерации и скачивания Excel-файлов прямо из браузера клиента.
